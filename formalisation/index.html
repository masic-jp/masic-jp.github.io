論文の形式化

数学の論文を、Lean 4 の Repository に。

数学の研究論文・プレプリントをお渡しいただき、その内容を Lean 4 / mathlib で形式化します。作業を終えた時点の Lean 4 の Repository を、形式化できた範囲と残った箇所の説明とともにお渡しします。Lean の環境構築や周辺のソフトウェア工学は、依頼者側では不要です。

01

形式化を、論文を渡すところから始める

自分の結果を Lean で形式化してみたい。しかし、Lean や mathlib の作法、ビルド環境、Repository の整備まで自分の手で行うには、時間も学習コストも重い。そうした研究者・数学者のためのサービスです。

依頼者にお願いするのは、論文またはプレプリントをお渡しいただくことだけです。Lean の予備知識は必要ありません。形式化がどこまで進み、どこで止まるのかを、実際の Repository で確かめていただけます。

02

進め方

作業期間はご相談のうえ着手前に決め、その中で形式化を進めます。最短 1〜3 営業日で納品しますが、論文の内容や分量によっては、より長い期間が必要になります。前後のご相談や納品後のご質問は、作業期間とは別に承ります。

03

お渡しするものと、お約束の境界

限られた作業期間で到達できる範囲は、論文の内容と mathlib の整備状況に大きく依存します。そのため本サービスは、成果を「完全な形式化」ではなく「作業を終えた時点の結果を、状態を隠さずにお渡しすること」として定義しています。

お渡しするもの

  • 作業を終えた時点の Lean 4 の Repository 一式
  • 形式化できた定義・命題・証明の範囲の明示
  • 残った部分と、進まなかった箇所（blocker）の明示どこで、何が理由で止まったかをお伝えします。

お約束しないもの

  • 論文全体の完全な形式化作業期間内に完了しない場合があります。その場合も、到達点と残りを明示してお渡しします。
  • 読みやすさを整えたリファクタリングや説明文書基本の作業では形式化そのものを優先します。必要な場合はオプションとしてご相談ください。
  • 納品後の追加作業着手前に決めた作業期間を超える作業は含まれません。継続をご希望の場合は、納品後に別途ご相談ください。
04

オプション

納品した Repository を土台に、次のような作業を別途ご相談いただけます。内容と条件は個別にご案内します。

A
リファクタリング
納品した Repository のコードを、読みやすく保守しやすい形に整理します。
B
原論文との忠実性チェック
形式化された定義や主張が、原論文の内容を正しく写しているかを確認します。
C
説明文書の作成
Repository の構成、原論文との対応、残った箇所の背景をまとめた文書を作成します。
D
mathlib への upstream
汎用性のある部分を、mathlib へ提出できる形に整えます。
05

位置づけと、お預かりする論文の扱い

本サービスは、一般社団法人 数理社会実装教育研究センター（MaSIC）が、形式化を研究現場に持ち込みやすくするために提供する学術支援です。

アカデミックな研究のために

大学・研究機関等でのアカデミックな研究を対象としています。研究費の範囲で試していただける水準の料金を想定しており、具体的な金額は決まり次第ご案内します。

未公開の内容をお預かりするにあたって

プレプリントや投稿前の原稿など、未公開の内容をお預かりすることを前提に、プライバシーポリシーと機密保持契約を現在準備しています。

整い次第、本ページに掲載し、ご依頼の前に必ずご確認いただきます。それまでの間にご相談いただく場合も、内容の取り扱いについては事前にご説明します。

06

よくあるご質問

ご依頼の前に、期待値を合わせておきたい点をまとめました。

論文全体が形式化されますか。

お約束はできません。到達できる範囲は、論文の内容と、必要な基礎がどこまで mathlib に整っているかに大きく依存します。作業期間内にどこまで進み、どこで止まったかを明示してお渡しします。

Lean を知らなくても依頼できますか。

できます。お願いするのは論文・プレプリントをお渡しいただくことだけで、Lean の環境構築や予備知識は必要ありません。納品する Repository の読み方については、納品時にご説明します。

どのような論文が対象ですか。

大学・研究機関等でのアカデミックな研究に関わる、数学の論文・プレプリントを対象としています。分野や内容によって到達できる範囲は変わりますので、ご相談の際に論文の概要をお知らせいただければ、事前に見通しをお伝えします。

投稿前の原稿を渡しても大丈夫ですか。

未公開の内容をお預かりすることを前提に、プライバシーポリシーと機密保持契約を準備しています。整い次第、本ページに掲載します。それまでにご相談いただく場合は、取り扱いについて事前にご説明したうえで進めます。

納品後、形式化を続けてもらえますか。

基本の作業には含まれませんが、継続作業やリファクタリング、説明文書の作成、mathlib への upstream などはオプションとして別途ご相談いただけます。

料金と申込方法はいつ決まりますか。

いずれも現在準備中（TBA）です。料金は研究費の範囲で試していただける水準を想定しています。決まり次第、本ページに掲載します。それまでは、メールでお問い合わせいただければ個別にご案内します。

まずは、論文の概要からご相談を

正式な申込方法は準備中ですが、ご関心のある方からのご相談はメールで受け付けています。対象となる論文やプレプリントの概要、特に形式化したい部分をお知らせいただければ、見通しをお伝えします。
