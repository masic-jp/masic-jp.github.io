論文の形式化

数学の論文を、Lean 4 の Repository に。

数学の研究論文・プレプリントをお渡しいただき、その内容を Lean 4 / mathlib で形式化します。作業を終えた時点の Lean 4 の Repository と、証明済み・未完了の区別や残った課題をまとめた報告書（PDF）をお渡しします。Lean の環境構築や周辺のソフトウェア工学は、依頼者側では不要です。

01

形式化を、論文を渡すところから始める

自分の結果を Lean で形式化してみたい。しかし、Lean や mathlib の作法、ビルド環境、Repository の整備まで自分の手で行うには、時間も学習コストも重い。そうした研究者・数学者のためのサービスです。

依頼者にお願いするのは、論文またはプレプリントをお渡しいただくことだけです。Lean の予備知識は必要ありません。形式化がどこまで進み、どこで止まるのかを、実際の Repository と報告書で確かめていただけます。

02

進め方

標準では、作業開始から 7 日以内に納品します。具体的な納品日は、ご依頼ごとにお伝えします。標準料金の前提として、形式化の作業は 72 時間で打ち切り、その時点の結果をお渡しします。事前のご相談と納品後のご質問は、作業とは別に無料で承ります。

04

納品物と、お約束の境界

限られた作業時間で到達できる範囲は、論文の内容と mathlib の整備状況に大きく依存します。そのため本サービスは、成果を「完全な形式化」ではなく「作業を終えた時点の結果を、状態を隠さずにお渡しすること」として定義しています。

お渡しするもの

  • Lean 4 の Repository（zip）作業を終えた時点の一式です。コードは読みやすく整えてお渡しします。GitHub 等へのアップロードはお客様側で行っていただきます。
  • 報告書（PDF）対象定理と Lean 側の対応、証明済み／未完了の区別、使用バージョンとビルド結果、残った課題をまとめます。

お約束しないもの

  • 論文全体の完全な形式化72 時間の作業で完了しない場合があります。その場合も、到達点と残りを報告書に明示してお渡しします。
  • 作業の自動延長継続をご希望の場合は、1 作業日（24 時間）あたり 10,000 円（税別）で追加作業を承ります。
  • GitHub 等への公開作業Repository は zip でお渡しします。公開先へのアップロードはお客様側でお願いします。

05

位置づけと、お預かりする論文の扱い

本サービスは、一般社団法人 数理社会実装教育研究センター（MaSIC）が、形式化を研究現場に持ち込みやすくするために提供する学術支援です。

アカデミックな研究のために

大学・研究機関等でのアカデミックな研究を対象としています。研究費の範囲で試していただけるよう、初回は 1 論文あたり 50,000 円（税別）としています。事前のご相談は無料です。

未公開の内容をお預かりするにあたって

プレプリントや投稿前の原稿など、未公開の内容をお預かりすることを前提に、プライバシーポリシーと機密保持契約を現在準備しています。

整い次第、本ページに掲載し、ご依頼の前に必ずご確認いただきます。それまでの間にご相談いただく場合も、内容の取り扱いについては事前にご説明します。

06

よくあるご質問

ご依頼の前に、期待値を合わせておきたい点をまとめました。

論文全体が形式化されますか。

お約束はできません。料金は論文 1 本を対象に形式化を進めるためのもので、完成を保証するものではありません。到達できる範囲は、論文の内容と、必要な基礎がどこまで mathlib に整っているかに大きく依存します。72 時間の作業でどこまで進み、どこで止まったかを、報告書で証明済み／未完了に分けて明示します。

どのように形式化を進めるのですか。

MaSIC が開発した AI エージェントによる作業ルーチンで進めます。Anthropic や OpenAI などの最新モデルを中心に構成しています。標準料金では作業を 72 時間で打ち切り、その時点の Repository と報告書をお渡しします。

Lean を知らなくても依頼できますか。

できます。お願いするのは論文・プレプリントをお渡しいただくことだけで、Lean の環境構築や予備知識は必要ありません。報告書に対象定理と Lean 側の対応、使用バージョンとビルド結果を記載しますので、Repository の読み方はそこから確認いただけます。

どのような論文が対象ですか。

大学・研究機関等でのアカデミックな研究に関わる、数学の論文・プレプリントを対象としています。分野や内容によって到達できる範囲は変わりますので、ご相談の際に論文の概要をお知らせいただければ、事前に見通しをお伝えします。

投稿前の原稿を渡しても大丈夫ですか。

未公開の内容をお預かりすることを前提に、プライバシーポリシーと機密保持契約を準備しています。整い次第、本ページに掲載します。それまでにご相談いただく場合は、取り扱いについて事前にご説明したうえで進めます。

納品後、形式化を続けてもらえますか。

継続は自動では延長しません。ご希望の場合は、1 作業日（24 時間）あたり 10,000 円（税別）で追加作業を承ります。納品した Repository と報告書を土台に、続きの作業を進めます。

急いで納品してもらうことはできますか。

特急でのご依頼を承ります。5 日以内の納品指定は +20,000 円（税別）、4 日以内の納品指定は +30,000 円（税別）です。それより早い納品指定は、AI の実行時間に制約があるため、個別にご相談ください。

納品された Repository を公開できますか。

Repository は zip でお渡しします。GitHub 等へのアップロードや公開はお客様側で行っていただけます。公開の可否や形はお客様の判断にお任せします。

料金と申込方法を教えてください。

初回は 1 論文あたり 50,000 円（税別）です。事前のご相談は無料で、メールで受け付けています。論文の概要と、特に形式化したい部分をお知らせいただければ、見通しと納品日をお伝えします。
